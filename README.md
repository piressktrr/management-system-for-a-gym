# spring-study

Repositório com foco em aplicar conceitos do Spring, Spring Boot, Spring Data JPA, Spring Web, Spring Web MVC e outros.
O objetivo é praticar o máximo possível realizando um back-end para um sistema de gestão de alunos em academia.

## Escopo
Não tem um escopo pré-definido, somente o limite de algumas semanas para que eu não faça overengineering nesse projeto.
